# 製図ツール (seizu-tool)

Excel感覚でグリッドに線を引ける軽量2D製図ツール。単一HTMLで動作。
要件: [drawing-tool-requirements.md](drawing-tool-requirements.md)

## 使う

`dist/seizu.html` をブラウザ(Chrome/Edge推奨)で開くだけ。配布もこのファイル1つをコピーするだけ。

JavaScriptの変数名・関数名や日本語を読みやすくした非圧縮版は `dist/seizu.readable.html`。こちらも単一HTMLで動作します。
両方のHTMLは同じ本文・CSS・画像・機能を含み、JavaScriptの圧縮の有無だけが違います(圧縮版は非圧縮版のJavaScriptをそのまま圧縮して作り、`npm test` と `npm run test:html` で一致を確かめています)。ヘルプの画像もHTMLに埋め込んでいるため、画像フォルダを一緒に配布する必要はありません。

### 基本操作

使い方は画面右上の **「？ ヘルプ」**(または **F1**)で、専門用語を使わず図付きで確認できます。ツールを使っている時に F1 を押すと、そのツールの説明が開きます。
全56項目に操作場所、具体例、できあがりの確認、うまくいかない場合の対処を用意しています。図は実際のアプリの画面を撮影したもので、クリックすると拡大でき、「原寸で見る」でボタン名や細部も確認できます。オレンジの番号と線だけが説明用の注釈です。

| 操作 | 方法 |
|---|---|
| 画面の構成 | 上段のタブ(ファイル/作図/寸法・記号/編集/表示・設定)で下段のボタンが切り替わる。「選択」と「線種・太さ・文字」は常に表示。ボタンにマウスを乗せると名前・キー・説明が出る |
| 操作ガイド | 作図中はマウスの横に「次に何をクリックするか」と長さ・角度などを表示(「表示・設定」→「操作ガイド」で切替)。クリックできる図形はマウスを乗せると薄い青で強調 |
| キー操作 | L直線 P連続線 R矩形 N正多角形 C円 A円弧 E楕円 Sスプライン T文字 D寸法 Hハッチ Bバルーン Xトリム Fフィレット Oオフセット / Esc=途中の操作を中止→選択ツールへ / Ctrl+Aすべて選択 / F1ヘルプ。直線・正多角形を描いている途中に数字を打つと長さ・大きさを指定 |
| 右クリックメニュー | 図形の上で右クリック(動かさずに離す)→ コピー・削除・回転・拡大縮小・反転・分解・線種・太さ・文字の大きさ・値の書き換え・寸法の値を中央に戻す・説明。何もない所ではすべて選択・全体表示など |
| 作図 | 直線/連続線/矩形/円/円弧/楕円/**楕円弧**(中心→コーナー→開始→終了)/スプライン/文字/**正多角形** をツールバーから |
| 正多角形 | 角数(3〜64)をボタンの右、大きさの決め方(**二面幅**=辺と辺の間 / **対角**=角と角の間 / **一辺**=辺の長さ)を画面下で選び、中心→辺の真ん中(対角・一辺は角)をクリック。向きは15°刻み(点スナップで吸い付いた点にはぴったり)。中心クリック後に数字+Enter、または中心X/Y・大きさ・角度の数値入力でも作図。できあがりは閉じた連続線(図心に「中心」スナップ) |
| 数値作図 | 下部パネルに始点X/Y・長さ・角度を入れて「作図」(作図中はEnterで数値確定)。数字は全角のまま打っても読める |
| 数値編集 | 図形を1つ選択するとパネルに値が入る。値を変えて**Enter**か欄を離れると即反映、**Esc**で打ちかけの値を取り消し。線=始点+長さ+角度 / 円=中心+**直径** / 円弧=中心+半径+開始角/終了角 / 矩形=左下+幅+高さ+**回転** / 楕円・楕円弧=中心+半径XY+**回転**(+開始/終了角) / 文字=位置+**回転** |
| 線分編集 | 選択中の連続線/スプラインを**もう一度クリック**すると線分単位で選択(オレンジ表示)され、その線分の始点X/Y・長さ・角度を個別に数値指定できる |
| コピー&ペースト | Ctrl+Cでコピー、Ctrl+Vでマウス位置に貼り付け。図形を**右ドラッグ**して離した位置に複製も可 |
| 線種・線の太さ・文字の大きさ | ツールバー右端の「線種」「太さ」「文字」。**図形を選択中**はその図形を変更(複数選択で一括、値が違えば「混在」表示)、**作図ツール中**は次に作る図形に使う(図形/文字/寸法・記号でそれぞれ覚える)。線種は外形線/かくれ線/中心線/想像線/細実線/補助線(補助線は印刷されない)。太さ「標準」=線種どおり。寸法・バルーン・部品表・記号は文字に合わせて枠も拡縮 |
| 移動(パン) | スクロール=上下、**画面右・下端のスクロールバー**(ドラッグ/空き部分クリックでジャンプ)、矢印キー、中ボタン(Space)+ドラッグ |
| 拡大縮小 | **Shift+スクロール / Ctrl+スクロール**(カーソル位置基準)、＋/－ボタン、「全体」で用紙全体表示 |
| 選択 | クリック / 空白からドラッグで範囲選択(Shiftで追加) / Ctrl+A すべて選択 |
| 編集 | ドラッグ移動・Ctrl+D複製・Delete削除・左右/上下反転。「編集」タブの **回転**(任意の角度、＋で左回り)と **拡大縮小**(倍率)は選択範囲の中心が基準(文字の大きさは変わらない) |
| トリム/延長/オフセット | 対象は**直線**(矩形・連続線は先に「分解」)。オフセットは距離を入れて対象クリック→**ずらす側をクリック**の2段階 |
| フィレット/面取り | 半径(サイズ)を入力して**2本の直線を順にクリック**(角がR/面取りになる)。矩形の角は先に「分解」 |
| 分解 | 選択した矩形・連続線・正多角形をバラバラの直線にする(トリム/フィレット等の前処理)。ねじ穴などのまとまり(グループ)は別々の図形に戻す |
| ハッチング | 角度・間隔を指定して閉じた図形(矩形/円/楕円/閉じた連続線)をクリック |
| バルーン/部品表 | バルーンは対象→円位置の2クリック(自動採番)。部品表はクリック配置しセルをダブルクリックで記入 |
| ねじ穴 | 呼び(M3〜M12)を選んでクリック。下穴円+ねじ谷3/4円弧(細実線)+中心線十字を一括生成(下穴はJIS並目から自動)。4図形は1つのまとまり(グループ)で、どれか1つをクリックすると全体が選ばれ、移動・複製・削除・回転もまとめてできる。範囲選択は全体が枠に入った時だけ。「分解」で別々の図形に戻る |
| 記号 | 粗さ(Ra記号)/公差枠(ダブルクリックで `//|0.05|A` 形式で編集)。溶接記号は引出線+テキストで |
| スナップ | グリッド/点スナップ(端点・中点・中心・四半点・交点)。引出線・バルーンの矢印の先(1点目)は、円・円弧の斜め45°の点にも吸着(円周の8か所) |
| 中心線モード | 線種「中心線」で作図中は、近くの辺の中点・円の中心にマーカーと十字軸が出て、**軸上ならどこでも吸着**(図形からはみ出して中心線を引ける)。端点への通常スナップは無効化 |
| 投影ガイド | 図形を選択すると特徴点から縦横の補助線。45°線配置で奥行き転写 |
| 寸法 | 寸法(2点+配置点、Shiftで平行寸法)/φ/R/角度(頂点+2点+半径)/C/引出線。値はダブルクリックで上書き(公差は `50±0.1` のように記入) |
| 寸法の値の移動 | 選択ツールで長さ寸法の**値を押したまま動かす**と寸法線に沿って移動。寸法補助線の外に出すと寸法線が値の下まで延び、矢印は外側から内向きになる。中央付近は中央に吸着、右クリック「寸法の値を中央に戻す」で元に戻る |
| 表題欄 | 欄をダブルクリックで記入(尺度・用紙は自動反映) |
| レイヤー | 「レイヤー」から表示/印刷を切替。非表示にした図形はクリック・範囲選択・吸着・トリム/延長の相手にならない(選択中なら選択から外れる) |
| Undo / Redo | Ctrl+Z / Ctrl+Y |
| 保存 / 開く | Ctrl+S / Ctrl+O(Chrome/Edgeは同じファイルへ上書き)。D&Dでも開ける |
| クラッシュ復元 | 起動時に未保存の変更があればバナーから復元 |
| 出力 | 「SVG出力」/「印刷」(印刷は倍率100%・実際のサイズを指定すると実寸) |

## 開発

- `npm install` — 初回のみ
- `npm test` — ロジックのテスト(2つの配布HTMLが圧縮の有無以外同じであることも確認)
- `npm run dev` — http://localhost:8000 で開発サーバー
- `npm run build` — 非圧縮版 `dist/seizu.readable.html` と、その JavaScript をそのまま圧縮した圧縮版 `dist/seizu.html` を必ず両方同時に生成
- `npx playwright install chromium` — 実画面の撮影・HTML検証用ブラウザを初回に準備
- `npm run help:capture` — 実際のDOM・CSS・Canvas描画を操作してヘルプ用の画面を撮影。画像と座標情報・撮影元のハッシュを更新
- `npm run test:html` — 両HTMLをファイルから開き、全ヘルプの本文・画像・画面レイアウトの一致、画像の埋め込み、検索、拡大表示、狭い画面を検証

画面や描画を変更したら `npm run help:capture` → `npm test` → `npm run build` → `npm run test:html` の順で更新します。撮影は1280×800・表示倍率100%で行い、操作の途中と結果を切り出します。図の注釈は撮影時の実座標に合わせたSVGで重ね、元の画面画像は描き直しません。
