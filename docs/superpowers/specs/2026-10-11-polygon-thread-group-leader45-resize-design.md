# 正多角形・ねじ穴のグループ化・引出線の45°吸着・マウス位置のずれ修正(設計メモ)

2026-10-11。ユーザー要望4点と、配布HTML2種の内容一致の保証。

## 1. 正多角形
- 道具 `polygon`(ボタン「正多角形」、キー N)。角数はボタン右の欄(3〜64、既定6)。
- 大きさの決め方(画面下の数値入力の、大きさ欄の名前のメニュー): 二面幅(既定)/対角/一辺。
  - 二面幅: 2回目のクリック=辺の真ん中。値=中心→辺の2倍。
  - 対角: 2回目のクリック=角。値=中心→角の2倍。
  - 一辺: 2回目のクリック=角。値=1辺の長さ。
  - 奇数角では二面幅=内接円の直径、対角=外接円の直径として扱う。
- マウスで描くときは向きを15°刻みに丸め、大きさはその向きへの投影で測る(グリッドから少しずれても傾かない)。
  点スナップで吸い付いた点(印が出ている)なら、その点にぴったり合わせる。
- 中心クリック後に数字+Enter、または 中心X/Y・大きさ・角度 +「作図」でも描ける。
- できあがりは閉じた連続線(`polyline`, `closed:true`)。既存の移動・回転・分解・ハッチ・線分編集がそのまま使える。
  閉じた連続線は図心を「中心」スナップ点・中心線モードのガイドに加える。
- 計算は `src/polygon.js`(純粋関数)。

## 2. ねじ穴のグループ化
- 図形に任意の `group`(番号)。同じ番号の図形は1つのまとまり。ロジックは `src/groups.js`。
- ねじ穴の4図形は作成時に同じ `group`。
- 選択: クリック・右クリック・右ドラッグ複製・Shift+クリックはまとまり全体。範囲選択は見えている仲間が全部枠に入った時だけ。
  Ctrl+A と、レイヤーを隠した時の選択整理も、まとまりを崩さない(隠れた仲間も一緒に選ぶ)。
- 複製(Ctrl+D・右ドラッグ)・貼り付けは新しい番号を振る(元と同じまとまりにならない)。
- トリムで切った残りは元のまとまりに残す。
- 選択ツールでマウスを乗せると、まとまり全体を水色で強調。
- 「分解」: まとまりは `group` を外して別々の図形に戻す(1段階)。矩形・連続線(正多角形)は従来どおり直線に。
- 汎用の「グループ化」ボタンは要望外のため作らない(提案のみ)。

## 3. 引出線の45°吸着
- 引出線・バルーンの1点目(矢印の先)だけ、円・円弧の円周の45°ごとの点(円弧は弧の範囲内)にも吸い付く。
  `findSnap(..., { perimeterStepDeg: 45 })`。ほかの道具の吸着は変えない。

## 4. マウス位置のずれ
- 原因: キャンバスの大きさを window の resize でしか取り直していなかった。タブ切替でボタンが2段になる・
  数値入力の欄が折り返す・復元の帯が出る等でキャンバスが縮むと、古い高さで座標を計算し、絵も引き伸ばされる。
  1280px幅で「編集」「表示・設定」タブを開くと縦に約26pxずれていた。
- 修正: `ResizeObserver` でキャンバスの大きさの変化に追従。大きさは `getBoundingClientRect` で小数まで取る。
- ヘルプの実画面撮影も同じ不具合で編集タブ等の図が縦に約5%つぶれていた → 撮り直しで解消。

## 5. 配布HTML2種の一致
- `build.mjs` は1回だけ束ねた JavaScript を非圧縮版に使い、圧縮版はそれを `esbuild.transform` で圧縮して作る。必ず両方同時に生成(`build:readable` は廃止)。
- `test/dist.test.js` と `scripts/check-html.mjs` で、JavaScript 以外が完全一致し、圧縮版の JavaScript が非圧縮版をそのまま圧縮したものであることを確かめる。
